# Exported reports

Self-contained `gxr-profiler` HTML reports for the findings pages.

- [Thermal mod before/after reports](thermal-mod/README.md) - seven stock-vs-modded comparison
  reports with labelled before/after run names.

GitHub shows `.html` files as source in its file viewer. Use the `Rendered` / `Preview` links in
the report indexes, or download an HTML file and open it locally.
