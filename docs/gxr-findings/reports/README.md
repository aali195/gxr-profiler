# Exported reports and investigation notes

[Findings index](../README.md#findings-index) | [Thermal mod before/after](../thermal-mod.md)

Self-contained `gxr-profiler` HTML reports for the findings pages, plus dated Markdown
investigations that are not run comparisons.

- [Thermal mod before/after reports](thermal-mod/README.md) - seven stock-vs-modded comparison
  reports with labelled before/after run names.
- [Soft-reboot and crash investigations](soft-reboots/README.md) - dated, sanitized investigations
  of unexpected restarts, including the 2026-11-17 SystemUI HWUI animation race.

GitHub shows `.html` files as source in its file viewer. Use the `Rendered` / `Preview` links in
the report indexes, or download an HTML file and open it locally.
