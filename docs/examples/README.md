# Examples

Small, sanitized snippets and command outputs that illustrate findings in
[`../README.md`](../README.md).

Guidelines:

- Keep only the lines that matter; link the command that produced them.
- Prefer read-only commands (`getprop`, `dumpsys`, `cat`, `ps`, `cmd ...`).
- Strip serial numbers, account names, Wi-Fi identifiers, and other personal data.
- Raw or unsanitized captures are not stored in the repository.
